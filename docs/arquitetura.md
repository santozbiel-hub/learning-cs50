# Guia do caderno de estudos

O caderno reúne a estrutura para os estudos de fundamentos de ciência da computação. O conteúdo começa pelo [README](../README.md).

## Como organizar um assunto novo

| Parte | Informação para registrar |
| --- | --- |
| Conceito | O problema que a técnica resolve. |
| Código | Um exemplo próprio, com as funções que realmente podem ser usadas em outro exercício. |
| Execução | A linguagem, o comando e uma entrada curta. |
| Verificação | Resultado esperado e um caso de borda. |

Em um exemplo sobre busca, registre o que acontece quando o valor está presente e quando ele está ausente. Se houver uma função de busca, descreva as entradas e o retorno.

Consulte o [curso CS50x](https://cs50.harvard.edu/x/) para os materiais oficiais.
